# Архитектура — CoinDetailCompare

## Обзор
Два процесса на одной Windows-машине:
- **C# Desktop** (UI-хост): камера, UI, SQLite, настройки, i18n.
- **Python-бэкенд** (визия-хост): OpenCV, DINOv3, FAISS, аномалии.

Данные (изображения/векторы/heatmaps/слои) живут на диске в `/coimg/`.
Сеть используется только для лёгкого JSON.

```
┌─────────────────────────────┐        JSON (HTTP/gRPC)      ┌──────────────────────────────┐
│  C# Desktop (WPF/WinUI)     │◄───────────────────────────►│  Python Backend (FastAPI/gRPC) │
│  • камера/стрим             │        (запрос/результат)    │  • OpenCV: кроп/сегментация/  │
│  • UI: фото/heatmap/слои    │                              │    выравнивание/фон           │
│  • SQLite (атрибуты/связи)  │                              │  • DINOv3 эмбеддинги          │
│  • настройки, i18n          │                              │  • FAISS (IndexIDMap)         │
│  • пути в /coimg            │──────────── путь ──────────►│  • SuperADD/AnomalyDINO        │
└─────────────────────────────┘     (только путь к кропу)    │  • heatmap 64×64/128×128       │
                                                             └──────────────────────────────┘
                                                              │ читает/пишет
                                                              ▼
                                                     ┌──────────────────┐
                                                     │  /coimg/ (диск)  │
                                                     │  фото, .npy/.bin,│
                                                     │  heatmap, JSON   │
                                                     └──────────────────┘
```

## Компоненты

### C# (UI-хост)
- Захват и стрим с веб-камеры; кнопка съёмки (аверс/реверс, пакетный режим).
- UI: предпросмотр, выбор эталона, % совпадения, переключение «текущее/базовое»,
  редактор векторного слоя, кнопки действий, форма «не определена»/Numista.
- SQLite: карточка серии, индивидуальная монета, справочники (из JSON).
- Настройки (язык, GPU/CPU, модель, каталоги, API-ключ), i18n.
- Обмен с Python: отправляет путь к кропу, получает JSON (топ-N, %, пути heatmap).

### Python (визия-хост)
- `preprocess`: автокроп, сегментация (HoughCircles/сегм. модель), выравнивание,
  нормализация фона, нормализация размера (≥512, целевое 1024).
- `embed`: DINOv3 (GPU ViT-H+/16 или CPU ViT-L/16 и ниже).
- `search`: FAISS (IndexIDMap), оба варианта перестановки сторон, % по сторонам.
- `anomaly`: SuperADD/AnomalyDINO, memory bank, heatmap.
- `index`: пересборка индекса из `.npy/.bin`.

### Хранилище
- SQLite — атрибуты и связи (см. DB_SCHEMA.md).
- FAISS — векторы, ID = `coin_id` (см. DB_SCHEMA.md).
- `/coimg/` — фото/векторы/heatmaps/слои (см. PIPELINE.md).

## Контракт JSON (примеры)
- Запрос поиска: `{ crop_path: ".../coimg/9001_obverse.png", mode: "obverse" }`
- Ответ поиска: `{ top: [ {coin_id, obverse_pct, reverse_pct, quality, etalons:[...]} ], sides: {...} }`
- Запрос аномалии: `{ crop_path, reference_ids: [..], heatmap_size: 128 }`
- Ответ аномалии: `{ heatmap_path, score, bbox, patches: [...] }`

## Переключение GPU/CPU и модель
- Конфигурация в настройках: `device=gpu|cpu`, `model=ViT-H/16|ViT-L/16|ViT-B/16`.
- GPU: CUDA 13.3+, RTX 5070 Ti. CPU: пониженная модель.
- FAISS: при росте коллекции — `IndexHNSWFlat` вместо `IndexFlatIP` (с сохранением IndexIDMap).

# CoinDetailCompare — UI / UX

## Экран «Съёмка»
- Живой стрим с веб-камеры.
- Кнопки: «Снять аверс», «Снять реверс», «Пакетный режим».
- В пакетном режиме: счётчик монет (1, 2, 3…), очередь «все аверсы → все реверсы»,
  привязка пар по порядку.
- До/после съёмки: поля «Альбом», «Страница», автономера монет (порядок съёмки).
- Ручная «крутилка» угла (при необходимости) + сетка/уровень.

## Экран «Сравнение / подтверждение»
- Наиболее близкое совпадение + **% совпадения** (аверс и реверс **отдельно**).
- Переключатель «текущее / базовое» фото.
- Выбор эталона **той же сохранности**.
- Heatmap (при аномалиях) поверх фото.
- Редактор векторного слоя (стрелки, обводки; вкл/выкл; норм. координаты 0.0–1.0).

## Кнопки действий
- «Поменять местами аверс/реверс»
- «Добавить как дубликат» (фото сохраняется)
- «Добавить в другой сохранности» (фото сохраняется)
- «Добавить как аномалию» (фото сохраняется + описание аномалии)
- «Определена некорректно / не определена» → вариант:
  - указать ссылку вручную (например, `https://ru.numista.com/3023`),
  - поиск в Numista по API (редактируемая строка поиска).

## Экран «Карточка монеты»
- Общая карточка серии (справка: эмитент, период, тип, годы, состав, масса,
  диаметр, толщина, форма, техника, ориентация, номер N#, ссылки, блоки
  аверс/реверс/гурт) — один раз на тип.
- Индивидуальные поля: год, монетный двор, качество, цена, альбом/страница/порядок.
- Фото аверс/реверс, heatmaps, слои, векторы (открыть/показать).

## Настройки
- Язык (RU по умолчанию, EN, +файлы переводов).
- Устройство: GPU (CUDA 13.3+) / CPU.
- Модель: ViT-H+/16 / ViT-L/16 / ViT-B/16.
- Каталог `/coimg/`, путь к БД, API-ключ Numista.
- Размер heatmap (64/128), порог аномалий.

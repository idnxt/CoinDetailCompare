# CoinDetailCompare — Конвейер предобработки (pipeline)

Вход: сырой кадр с камеры. Выход: нормализованный кроп монеты (аверс/реверс),
эмбеддинг, (опц.) heatmap.

## Шаги

1. **Захват кадра** — по кнопке; в пакетном режиме — последовательность кадров
   (все аверсы → все реверсы), привязка пар по порядку.

2. **Детекция монеты** (локализация):
   - Основное: OpenCV `HoughCircles` / контур (Canny → findContours).
   - Опция: лёгкая сегментационная модель (сегмент круга/контура).
   - Учёт **нестрого круглых** монет: если круг не сходится — взять минимальный
     вписанный/описанный эллипс или контур с закруглением.

3. **Сегментация края/гурта** — вырезка строго по краю гурта.
   - Круг: маска по окружности; эллипс/контур: маска по контуру.

4. **Нормализация фона** — всё вне маски залить нейтральным (серый/белый),
   чтобы стол/фон не влиял на эмбеддинг.

5. **Выравнивание угла (rotation alignment)**:
   - **Авто** (при совмещении с эталоном): ключевые точки / RANSAC по патчам DINOv3
     (при наличии эталона того же типа) → оценка угла → поворот.
   - **Ручная** «крутилка» в UI (сетка/уровень, шаг 1°) — при съёмке/до уточнения.
   - Медальная/монетная ориентация учитывается при выравнивании эталонов.

6. **Нормализация размера** — кроп в квадрат, масштаб до **≥ 512×512**, целевое
   **1024×1024** и выше; сохранение в `/coimg/{id}_{side}.png`.

7. **Эмбеддинг** — DINOv3 (GPU ViT-H+/16; CPU ViT-L/16 и ниже) → вектор
   `/coimg/{id}_{side}.npy`.

8. **Поиск** — FAISS по аверсу и реверсу; проверка обоих вариантов перестановки сторон.

9. **Аномалии (опц.)** — при подтверждении/наличии эталонов: memory bank патчей
   → патч-расстояния → heatmap (см. ANOMALY.md).

## Вариант «перепутаны стороны»
Пользователь мог снять сначала реверс, потом аверс. Поиск проверяет оба варианта:
- **A–A + R–R** (направлено): аверс→аверс эталона, реверс→реверс эталона;
- **A–R + R–A** (перестановка): аверс→реверс эталона, реверс→аверс эталона.
Отображается лучший вариант + % по сторонам; кнопка «поменять местами аверс/реверс».

## Выходы
- `/coimg/{id}_{side}.png` — нормализованный кроп.
- `/coimg/{id}_{side}.npy` — вектор.
- `/coimg/{id}_{side}_heatmap.png` — heatmap (опц.).

# CoinDetailCompare — Интеграция со справочниками / Numista

## Ручная ссылка (по умолчанию)
- Пользователь вводит ссылку на монету, например `https://ru.numista.com/3023`
  (5 рублей 1991 СССР).
- Валидация формата ссылки (домен numista, числовой/иерархический ID).
- Ссылка привязывается к карточке серии/монеты (`numista_url`).

## Поиск по Numista API (если есть ключ)
- Пользователь вводит текстовый запрос (редактируемая строка).
- Выполняется текстовый запрос к API; отображаются найденные варианты.
- Пользователь выбирает вариант → данные попадают в карточку серии
  (наименование, эмитент, период, состав, масса, диаметр, ориентация,
  блоки аверс/реверс/гурт, ссылки, номер N#).
- Документация API (текстовый поиск): https://ru.numista.com/api/doc/index.php

## Привязка к данным
- Поля из ответа API маппятся в поля `coin_type`.
- Номер `N#…` сохраняется как `numista_n`; ссылки (`Y#`, `Schön#`, `PCGS#`) — в `links`.

## Примечания
- Интеграция по референсу OpenNumismat (в котором уже есть интеграция с Numista API) —
  **без копирования кода**, только как ориентир.
- При отсутствии API-ключа используется только ручная ссылка.

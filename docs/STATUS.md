## Открытые решения (блокируют/влияют на следующие фазы)
1. Живой API Numista: numista.com возвращает 403 — ждать доступ/проверить позже.
2. Экспорт OpenNumismat: сверка `scripts/export_opennumismat.py` с реальным .db.
3. Нестрого круглые монеты: HoughCircles vs лёгкая сегментационная модель.
4. Авто-выравнивание угла (RANSAC по патчам DINOv3): ручная «крутилка» в карточке
   готова; авто-режим — отложен.
5. Наблюдение: стабильность живого бэкенда (один раз умер с чистыми логам —
   причина не установлена; следить за `logs/backend.err.log`).

Решено: выбор детектора аномалий (auto-режим работает live на GPU, heatmap 64/128);
тип вектора DINOv3 (vit-h-plus-16, пул, dim 1024, CPU==GPU bit-identical);
хранение дубликатов (отдельные строки `coin` со связью `etalon_id` + `source_kind`);
сборка C# (Release, 0 ошибок, xaml-smoke exit=0); дисциплина GPU (lock + release
после каждого запроса, остаток ≈300 MB драйверного контекста принят).

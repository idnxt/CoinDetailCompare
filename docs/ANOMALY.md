# CoinDetailCompare — Детекция аномалий

## Подход
Сравнение **плотных патчей** (patch-level cosine distance) проверяемой монеты с
«нормальными» эталонными монетами того же типа из БД → тепловая карта (heatmap)
и bounding box аномалий. Патч-эмбеддинги DINOv3 подходят для методов
PatchCore / AnomalyDINO / SuperADD.

## Выбор метода
- **Приоритет: SuperADD** (бэкбон `anomalib`, по умолчанию **ViT-H+/16**),
  поддержка memory bank и тепловых карт.
- **Fallback: AnomalyDINO** — training-free, лёгкая интеграция. Официально
  поддерживаемые B/L; конфигурация H+ не имеет официальной валидации; по
  официальным тестам **DINOv2 иногда превосходит DINOv3** → при недостаточной
  точности DINOv3 можно откатиться на DINOv2-бэкбон.
- **anomalib** (Intel) — промышленная библиотека для интеграции.

## Алгоритм
1. Для монеты-типа берутся **1–5 «нормальных» эталонов** с наибольшим сходством
   из БД (по поиску).
2. По эталонам формируется **memory bank патчей** (патч-эмбеддинги).
3. Для проверяемой монеты вычисляются патч-эмбеддинги; для каждого патча
   считается расстояние до ближайших патчей в memory bank (cosine / Mahalanobis).
4. Собирается карта расстояний → **heatmap** (размер **64×64** или **128×128**,
   конфигурируемо) → нормализация/колорбар → наложение поверх фото.
5. Выделяются зоны с превышением порога → bounding box аномалий;
   общий score аномалии.

## Интеграция в UI
- Переключатель «текущее / базовое» фото — визуальное отслеживание различий.
- Heatmap накладывается поверх текущего фото (полупрозрачно).
- Пометка аномалии: флаг `is_anomaly=1`, описание, место (векторный слой).
- Сохранение: `/coimg/{id}_{side}_heatmap.png` + `.npy` (матрица 64×64/128×128).

## Выходы
- `heatmap_path`, `score`, `bbox`, список аномальных патчей.
- Векторный слой с обводкой/стрелками на месте аномалии (норм. координаты 0.0–1.0).

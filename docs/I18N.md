# CoinDetailCompare — Мультиязычность (i18n)

## Принципы
- В настройках — **подключаемые языки**: включается/выключается набор языков.
- **По умолчанию: русский.** Второй язык — **английский.**
- Опционально — любые другие языки, для которых **сформирован файл перевода**.
- Все строки UI — через ключи локализации (не хардкод в разметке).

## Формат файла перевода
Пространство имён (namespace) по экранам/компонентам. Пример (JSON):

```json
{
  "capture": {
    "shoot_obverse": "Снять аверс",
    "shoot_reverse": "Снять реверс",
    "batch_mode": "Пакетный режим",
    "album": "Альбом",
    "page": "Страница",
    "order": "Порядок"
  },
  "compare": {
    "match_obverse": "Совпадение аверса",
    "match_reverse": "Совпадение реверсa",
    "switch_sides": "Поменять местами аверс/реверс",
    "current": "Текущее",
    "base": "Базовое"
  },
  "actions": {
    "duplicate": "Добавить как дубликат",
    "variant": "Добавить в другой сохранности",
    "anomaly": "Добавить как аномалию",
    "not_determined": "Определена некорректно / не определена"
  },
  "quality": { "G": "G", "VG": "VG", "F": "F", "VF": "VF", "XF": "XF", "AU": "AU", "UNC": "UNC" }
}
```

Файлы: `i18n/ru.json` (по умолчанию), `i18n/en.json`, `i18n/{lang}.json`.
Справочные значения (сохранности, гурты, ориентации, страны, номиналы) берутся
из таблицы `reference` (столбцы `ru`, `en`, …) и JSON по референсу OpenNumismat.

## Локализация чисел/единиц
- Единицы (g, mm, RUB, TWD) и даты — локализуемые форматы.
- Ссылки/номера (N#966, Y#551) — не переводятся.
